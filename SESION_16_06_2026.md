### 3. Endpoints del backend — M9 Proyectos

| Método | Endpoint | Qué hace |
|---|---|---|
| POST | `/projects/` | Crear proyecto nuevo |
| GET | `/projects/` | Listar todos con resumen |
| GET | `/projects/{id}` | Detalle completo |
| POST | `/projects/{id}/baseline` | Capturar baseline manual |
| POST | `/projects/{id}/audit-and-baseline` | Audit real + baseline en un paso |
| POST | `/projects/{id}/close` | Cerrar + generar PDF automáticamente |

---

### 4. Flujo completo de un proyecto

```
1. Crear proyecto → POST /projects/
   { client_name, site_url, plan, notas }
   Estado: DRAFT

2. Capturar baseline → POST /projects/{id}/audit-and-baseline
   { url: "https://sitio.cl" }
   → Hace audit real (M1), guarda score inicial
   Estado: OPEN

3. Trabajar tickets → /tickets + /agents
   (días o semanas de trabajo)

4. Cerrar proyecto → POST /projects/{id}/close
   → Hace audit final, genera PDF antes/después
   → Verifica garantía (+15 pts mínimo)
   Estado: CLOSED

5. Descargar PDF → GET /report/download/{id}
```
